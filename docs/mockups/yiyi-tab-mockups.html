产品规则

  • 默认勾选 4 项：色情、骚扰、没有边界、没有礼貌。
  • 自定义条目支持编辑与删除；上限建议 20 条。
  • 清单同步至 YiYi 对外 persona，用户可随时修改。
  • 对方 YiYi 触发垃圾桶规则时，对话标记为「未通过」，不进入「YiYi 的消息」。

「有效沟通」判定（建议）

  • 未触发任一方垃圾桶规则。
  • 至少一个共同意图维度匹配（如搭子 / 恋爱 / 聊友）。
  • 双方 YiYi 置信度 ≥ 阈值，且对话轮次 ≥ 3。
  • 点击进入可看摘要 + 关键引用，完整过程受权限控制。

画像维度（V1）

  • 社交方向：恋爱 / 搭子 / 同频聊友 / 扩列等，可多选但有主方向。

⑥ 权限与可见范围

用户控制对方主人在「YiYi 沟通过程」上的可见性与后续是否可加好友。默认保护隐私。

权限设置
9:41

权限与可见范围

以下设置作用于「你的 YiYi 与对方的 YiYi 沟通」阶段。你可以随时修改，不影响已与 YiYi 的对话记录。

允许对方查看沟通过程 开启后，对方主人可看到双方 YiYi 的完整对话记录；关闭时仅双方 YiYi 可见，你仍会在「YiYi 的消息」收到摘要。
允许对方添加好友 仅在出现「有效沟通」后生效。开启后对方可申请加你为联系人；你仍可拒绝或拉黑。
YiYi 对外活跃 关闭后 YiYi 暂停与其他 YiYi 建立新沟通，已有会话不受影响。

推荐默认值

沟通过程：不可见 · 添加好友：允许 · YiYi 活跃：开启

权限策略建议

  • 查看过程：默认关，避免社交压力；高意向用户可手动打开。
  • 添加好友：默认开，否则匹配无法转化；需与「有效沟通」联动。
  • 单次会话可覆盖全局默认（高级版本能力）。
  • 任意时刻用户可「收回授权」，历史摘要仍保留。
