# 聊天本地存储原则

## 原则

**所有聊天内容只保存在用户设备本地，服务端不持久化聊天记录。换设备或卸载后，聊天内容丢失。**

适用于：

- 普通私聊（`normal`）
- 单向分身对话（`oneway`，本就为本地）
- AI 护场群聊（`guardian` 群消息）

## 服务端仍做什么

| 能力 | 是否落库 | 说明 |
|------|----------|------|
| 账号 / 联系人 / 好友 | 是 | 非聊天内容 |
| 护场群元数据（谁、场景、角色列表） | 是 | 非聊天内容 |
| 私聊 / 群聊消息正文 | **否** | 仅 `relay` + WebSocket 推送给在线对方 |
| 护场风险提示（owner hints） | 是 | 辅助元数据，非对话气泡；仅被护方可查 |
| Mol 建议 / 护场 AI 生成 | 临时请求 | 不把聊天历史写入服务端 |

## 客户端

- 普通私聊：`normalChatLocalStorage`（按 `peerUserId`）
- 单向：`onewayLocalStorage`（按手机号）
- 护场群：`guardianGroupLocalStorage`（按 `groupId`）

## 产品含义

- 对方**离线**时发送的消息，对方上线后**收不到**（无服务端历史可拉）。
- 同一账号换手机**无法恢复**聊天记录。
- 会话列表预览由**本机本地**最后一条消息汇总。

## 相关 API 行为

- `GET /api/messages`、`GET /api/messages/conversations` → 恒空列表（兼容旧客户端）。
- `POST /api/messages` → 校验联系人后转发，不写 `messages` 表。
- `GET /api/guardian/groups/:id/messages` → 恒空；发送时客户端附带 `lastMessages` 供护场 AI 上下文。
