## 一、定位与目标

### 1.1 产品对外心智（传播时统一口径）

面向 **30 岁以下** 用户，偏 **娱乐、社交前置**，不是正式通讯录：

| 功能 | 传播一句话 |
|------|------------|
| **辅助聊天** | 正式聊之前，先练怎么说 |
| **单向探索式朋友圈** | 不刷屏，挂出来给熟人探索 |
| **AI 群聊** | 2 真人 + N 个 AI，聊的时候拉护场角色进场 |

**主推门面（短视频）**：**AI 群聊（护场群）**——戏剧冲突强、30 秒能看懂。  
辅助聊天、探索墙作为深度能力，单条视频不混讲。

### 1.2 传播目标

| 阶段 | 目标 |
|------|------|
| 冷启动 | 验证「是否有人觉得有意思」（播放、完播、评论求链接） |
| 转化 | 主页访问、私信内测、护场群创建 |
| 融资素材 | 3–5 条高光剪辑 + 播放/评论截图，写入 BP「传播验证」 |

**不追求**：MVP 未完成时提前投流或官号大规模运营。

---

## 二、为什么选抖音录播

- 产品本质是 **关系小剧场**，不是功能说明书；对话冲突、神回复适合竖屏短视频。
- 成本低于应用商店买量；比双边社交冷启动更现实。
- 护场 AI **主动接话** 有综艺感，易做系列账号（如「护场姐妹团」）。
- 录播可同时用作：抖音发布、路演 demo、种子轮 BP 开场。

---

## 三、内容原则（避免像软广）

### 3.1 结构

1. **前 5 秒**：只呈现冲突（对方施压 / 暧昧逼答），无 Logo、无功能名。  
2. **中段**：护场 AI 出场（字幕/色条区分人设），可选仅被护方可见的风险提示条。  
3. **后 3 秒**：留讨论点或金句；产品名/搜索词放末尾或评论区置顶。

### 3.2 制作

- 竖屏 9:16，大字幕，对方每句一切镜。  
- AI 出场：**专属色 + 短音效**，像嘉宾入场。  
- 对话口语化，允许停顿、口头禅；过于工整会像广告。  
- **一条视频一种情绪**：爽 / 好笑 / 清醒，不塞多功能。

### 3.3 账号

- 优先 **人设号**（暧昧期姐妹、大学生吃瓜等），弱官方腔。  
- 系列化：**同一世界观连做 10 条**，比零散单条更易起号。

### 3.4 合规（平台与未成年人）

- 文案避免：煽动男女对立、明示「识渣男/教分手」、未成年恋爱露骨、引战辱骂。  
- 改为：**练眼力、别被带节奏、搞笑护场、边界提醒**。  
- 涉及青少年场景时，不展示明显未成年真人形象；必要时片尾加「娱乐排练/仅供参考」类提示。

## 四、爆点场景库（录播脚本方向）

### S 级（系列首发，优先拍）

| 编号 | 场景 | 梗概 | 护场角色建议 |
|------|------|------|----------------|
| S1 | 暧昧逼表态 | 「你不来就是不爱我」 | 林姐点破 + 周予安讲边界 |
| S2 | 连发施压 | 对方三连问，气氛僵 | 阿跳硬转话题 |
| S3 | 要隐私 | 「把定位发我」「查手机」 | 风险提示条 + 铁柱/周予安式边界 |

### A 级（起量后第二条产品线）

| 编号 | 场景 | 梗概 | 对应功能 |
|------|------|------|----------|
| A1 | 探索墙好奇 | 熟人点进「理想型」等话题 | 单向探索式朋友圈 |
| A2 | 同一句话三种说法 | 对比三种 Mol 风格回复 | 辅助聊天 |

### 慎做门面（真实但难传播 / 合规敏感）

- 亲子控制、师生压迫——可作能力演示，**不作抖音系列主打**。

## 五、转化与数据指标

### 5.1 转化路径（由轻到重）

1. 评论区置顶：内测说明 / 搜索词  
2. 主页简介：产品一句 + 私信关键词  
3. MVP 稳定后：小程序/下载链接（资质就绪再挂）

### 5.2 关注指标

| 指标 | 说明 |
|------|------|
| 完播率 | 前 3 秒是否留住 |
| 评论率 | 「求链接」「这不就是我吗」类占比 |
| 主页访问 | 内容是否驱动好奇 |
| 内测进群 / 护场群创建 | **传播是否带来真实行为**（融资关键） |
| 护场群 D7 留存 | 抖音解决「有意思」；留存解决「会不会再来」 |

单条 10 万+ 播放且评论求玩法 → 可写入融资材料「传播验证」。

## 六、与融资叙事的关系

- 抖音验证 **需求直觉与传播面**，不能替代留存与付费数据。  
- 建议路演结构：30 秒 montage（护场群高光）→ 早期播放/评论数据 → 内测留存（若有）。  
- 对外品类表述：**Z 世代关系前置娱乐 / 2+N 护场群聊**，非「替代微信」。
