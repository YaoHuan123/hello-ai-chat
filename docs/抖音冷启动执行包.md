## 一、S1 护场群 · 30 秒分镜与台词

**系列**：护场姐妹团 · 第 1 条  
**场景编号**：S1 · 暧昧逼表态  
**功能**：恋爱暧昧护场群（林小姐 + 周予安，可选阿跳收尾）  
**账号人设**：暧昧期姐妹吃瓜 / 练眼力别被带节奏  

### 1.1 结构（30–35 秒）

| 秒数 | 画面 | 字幕/音效 | 说明 |
|------|------|-----------|------|
| 0–3 | 黑屏或聊天列表一闪 | 无产品名 | 钩子：压迫感 |
| 3–8 | 对方连发（右气泡） | 大字幕逐条弹出 | 只呈现冲突 |
| 8–12 | 我方犹豫（左气泡，可选省略号） | 「……」 | 不替用户说话 |
| 12–18 | **林小姐**出场（紫色/深色条 + 头像） | 林小姐：「喜欢一个人不用逼对方当场表态。」 |  catalog 原句 |
| 18–24 | **周予安**出场（蓝色条） | 周予安：「见面的事改天单独约也行。」 | 给台阶、讲边界 |
| 24–28 | 可选 **阿跳**（橙色条） | 阿跳：「你俩先别辩论了，今晚月亮挺圆。」 | 气氛松绑 |
| 28–32 | 定格最后一句 / 留白 | 无 Logo | 结尾不硬广 |
| 32–35 | 可选片尾 0.5 秒 | 「娱乐排练 · 仅供参考」小字 | 合规 |

### 1.2 台词定稿（录屏前改人名即可）

**对方（施压）：**
1. 「你今晚不来，就是不在乎我。」
2. 「别人都能秒回，就你特殊？」
3. 「你到底把我当什么？」

**我方（可选，可不显示）：**
- 「……我这边真的在忙。」

**林小姐（护场 · 偏点破）：**
- 「哎等等，你这话听着耳熟——喜欢一个人，不用逼人家当场表态吧？」

**周予安（护场 · 边界）：**
- 「予安说一句：见面可以聊，但得看人家什么时候方便，别用「不来就是不爱」卡人。」

**阿跳（可选 · 打岔）：**
- 「停停停，这严肃程度我以为在考研复试！先聊点不费脑子的？」

### 1.3 实机录屏步骤（App 内）

1. 群聊 → 发起群聊 → 用途选 **恋爱暧昧** → 拉 1 位好友（或双机/小号扮演对方）  
2. 群成员里启用 **林小姐、周予安**（+ 阿跳）  
3. 按台词顺序：对方发 3 条 → 等护场 AI 接话（或预录后剪辑对齐）  
4. 录屏 9:16，保留护场角色 **色条/头像/昵称**  
5. 剪辑：每句一切、大字幕、护场出场加轻音效  

### 1.4 发布后

- **置顶评论**：「内测招募：私信发 **护场** 进体验群（限 XX 人）」  
- **简介一句**：关系聊天里，AI 护场角色帮你接话、点边界（勿写「识渣男」）  
- **不在前 5 秒出现** App 名、下载链接

## 二、抖音数据 Tracking 表

每条视频复制一行填写。建议用 Excel / 飞书表格，每周日汇总。

### 2.1 单条视频字段

| 列名 | 填什么 | 融资用途 |
|------|--------|----------|
| video_id | 自编号，如 S1-001 | 追溯 |
| publish_date | 发布日期 | 时间线 |
| scene_code | S1 / S2 / S3 / A1… | 对比哪类场景有效 |
| title_hook | 前 5 秒钩子一句话 | 复盘爆款公式 |
| duration_sec | 成片秒数 | — |
| views_24h / views_7d | 24h / 7d 播放 | 基础量 |
| completion_rate | 完播率（_creator 后台） | 前 3 秒是否留住 |
| likes | 点赞 | 弱信号 |
| comments_total | 评论总数 | — |
| **comments_ask_link** | 含「链接/怎么下/内测/求」等评论数（人工数） | **核心 KPI** |
| **comments_resonance** | 「像我/真实/这不就是我」类评论数 | 需求共鸣 |
| shares | 分享 | 传播意愿 |
| profile_visits | 主页访问 | 好奇转化 |
| dm_count | 私信人数（人工记） | **强验证** |
| join_group_count | 进群人数 | **最强验证** |
| notes | 爆款/翻车原因 | 下周选题 |
| screenshot_path | 代表性评论截图文件名 | 贴 BP |

### 2.3 每周复盘三问

1. 哪条 **钩子** 完播最高？下一条复用还是换场景？
