聊天界面设计稿（4 个方案）

每个原型都覆盖以下要素，用不同的布局组织方式呈现，便于你横向对比挑选或混搭。点击 "查看" 单独打开手机视图。

必备元素清单

  • 当前 Mol 名称展示 + 切换入口
  • 一键触发 Mol 推荐按钮
  • 单向 / 普通 聊天模式切换
  • 对方头像 + 名称 + 在线状态
  • 消息时间戳
  • Mol 推荐内容的展示方式
  • 标准输入框 + 发送按钮

方案 A · 顶栏 Mol + 工具条推荐

顶栏放对方信息和模式开关；下方一条独立的 Mol 工具条，左侧是当前 Mol 切换胶囊，右侧是醒目的 "Mol 推荐" 按钮。推荐结果以浮层卡片出现在输入框上方。

适合：把 Mol 当作"持续显示的工具"，强调当前用的 Mol。
取舍：顶部占两行，纵向空间略少。

方案 B · 输入框上方工具条 + 内联建议

顶栏只放对方信息；Mol 选择、模式切换、Mol 推荐全部聚合在输入框正上方一行。推荐结果以"草稿气泡"形式出现在我方一侧，点击直接发送。

适合：把所有控件靠近拇指；推荐结果上下文连贯。
取舍：底部工具条略重，需注意视觉层级。
查看 B

方案 C · 占位原位展开 + 建议框内管理 Mol

顶栏不展示当前 Mol。推荐入口为「我方下一条」虚线占位，点击后在同位置展开 Mol 建议卡片；卡片内提供「修改 Mol」入口（示意中可再打开底部选择列表）。模式切换为顶栏右上角胶囊。同页含三种状态示意。

适合：推荐与占位同位；Mol 相关操作集中在建议流程内，顶栏更简洁。
取舍：展开卡片会拉长列表，需预留滚动空间。
查看 C

方案 D · 输入区图标化 + 底部抽屉

对方名旁挂一颗"当前 Mol"小胶囊，单向/普通做成 Segmented Control。Mol 推荐做成输入框左侧的 ✨ 图标按钮，推荐结果以底部抽屉式出现。附赠单向模式对比稿。

适合：整体最克制，把更多空间留给消息内容。
取舍：图标对新用户认知成本略高，需要 tooltip。
