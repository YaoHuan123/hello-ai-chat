日常 Tab · 布局方案

新增底部 Tab「日常」：上半为发布入口（拍照 / 拍视频 / 写文字 / 语音），下半为已发布的日常记录流。

与「朋友圈 · 我的动态」的区别：「日常」侧重多媒体生活记录与快速发布；「我的动态」侧重文字观点供好友探索引用。以下均为 390px 手机原型，含底部 Tab 栏示意。
  • 方案 A · 顶部四图标横排 发布区白底卡片 + 图标标签，下方按日分组记录流。结构清晰，适合作为主方案。
  • 方案 B · 2×2 发布网格 大触控区、类型说明更醒目；记录区混排图文 / 视频 / 语音卡片。
  • 方案 C · 底部发布 Dock 记录流占满屏，发布入口固定在 Tab 栏上方；单手操作友好。
  • 方案 D · 列表式入口 与现有「朋友圈」入口列表风格一致，四行发布类型 + 下方记录。
  • 空状态 · 3 款对比 尚无记录时的引导文案与发布入口形态。
