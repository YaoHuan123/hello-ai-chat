Mol 建议面板 · 5 种方案

场景：聊天室点击「Mol」后，在输入框上方展示 AI 生成的 3 条回复备选。 每稿均在手机聊天上下文中预览，包含标题、刷新/关闭、Mol 资料说明、修改入口与三条示例文案。

必备元素

  • 标题「Mol 建议」+ 刷新 / 关闭
  • 「建议基于『我的 Mol』中的资料」+「修改 Mol」
  • 最多 3 条可点击采纳的回复文案
  • 与下方输入框、聊天气泡的层级关系清晰
  • 加载态 / 空态 / 错误态（实现时可复用同一布局）

方案 A 接近现版

浮层卡片叠在输入框上方，白底圆角，建议项为全宽按钮行。

适合：改动最小，与当前 ChatRoom 结构一致。

方案 B · 底部抽屉

半屏 Bottom Sheet，顶栏拖拽条，建议列表留白更大，操作区固定在抽屉内。

适合：文案较长、需要专注挑选时；拇指友好。
查看 B

方案 C · 草稿气泡

建议以「我方待发气泡」形态出现在聊天区，虚线边框 + 轻绿底，贴近消息流。

适合：强调「点一下就能发」；与 chat-C 占位思路一致。
查看 C

方案 D · 紧凑列表

窄标题栏 + 编号列表，每条一行预览 + 右侧「用这条」，信息密度高。

适合：屏幕空间紧张、用户熟悉 Mol 功能。
查看 D

方案 E · 分卡操作

每条建议独立卡片，底部「采用并发送」主按钮，Mol 资料区做成顶部 banner。

适合：降低误触；长文案可读性最好。
